# Family-Rubric Mapping Pre-registration (Redacted Public Copy)

Version: v1.2 redacted for anonymous review.

The mapping links analytic rubric traits to eight feature families. The mapping is operational: each feature family is treated as a partial proxy for measurable linguistic evidence, not as the full construct of the rubric trait.

Families: `lex`, `vocab_grade`, `case_marker`, `morph_prop`, `syn`, `dis_nonSBERT`, `dis_SBERT`, `meta`.

Trait types: Surface=`expression_2`; Discourse=`organization_1`; Content=`content_1`.
