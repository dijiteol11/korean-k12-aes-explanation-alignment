# Restricted Corpus Access

The raw Korean K-12 essay corpus is not included in this repository. To reproduce raw-data analyses, obtain the corpus from the official AI-Hub / data-provider channel under its own access terms, place the raw files in a local private directory, and point `AES_DATA_ROOT` to that directory.

Do not commit raw essays, identifiable metadata, provider credentials, or model-output logs to this public repository.
